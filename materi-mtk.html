ANGGOTA 01

Model Matematika Kevin

Lihat Materi

Variabel

x = Harga satu buah kipas angin smart
y = Harga satu buah Reglow Tree

Persamaan

x + 5y = 400.000
4x + 3y = 495.000

Metode Campuran

1. Eliminasi
x + 5y = 400.000 | ×3
4x + 3y = 495.000 | ×5
3x + 15y = 1.200.000
20x + 15y = 2.475.000
-17x = -1.275.000
17x = 1.275.000
x = 75.000
2. Substitusi
x + 5y = 400.000
75.000 + 5y = 400.000
5y = 400.000 - 75.000
5y = 325.000
y = 325.000 : 5
y = 65.000
Kesimpulan

Jadi, harga satu kipas angin smart adalah Rp75.000 dan harga satu Reglow Tree adalah Rp65.000.
